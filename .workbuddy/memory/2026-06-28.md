## 夜间模式餐次标签修复（03:17~03:30）

### 问题根因（两层bug叠加）
1. **模块级样式常量快照**：`inputStyle` / `recordInputStyle` 在模块加载时创建，捕获了日间模式颜色值（如 `colors.ink = "#1A1A1A"`），之后永远不更新
2. **子组件闭包**：定义在 TodayScreen 外部的函数组件（MealCompareRow、CardHeader、PillButton、DeficitHero、MetricMini/MetricDelta、MacroRow、ActualFoodInputSection、FoodTagEditorModal、DietPlanLogicModal、SmallInput、AdjustmentSummaryCard）使用直接引用的 `colors` 对象，可能存在渲染时序问题

### 修复方案
- 所有子组件内部添加 `const c = useBentoTheme().colors;` 获取主题感知的颜色
- `inputStyle` / `recordInputStyle` 从常量改为函数：`getInputStyle(c)` / `getRecordInputStyle(c)`
- TodayScreen 添加 `useBentoTheme()` 钩子并传入 `c`
- 最终结果：index.tsx 中零 `colors.` 运行时引用（仅保留 import）
- 修改文件：`apps/mobile/app/(tabs)/index.tsx`
