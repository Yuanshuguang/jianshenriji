# Soft Gradient Wellness · 柔和渐变康养

> 像晨光一样温柔地推着你走。

## 命名

**Soft Gradient Wellness**（柔和渐变康养）

## 哲学

健身不该让你焦虑。这一套语言把"管理身体"这件本来有点紧绷的事，翻译成一段柔和的晨间流程。它来自 Apple Fitness 的圆环、Calm 的渐变天空、Headspace 的圆润字体——所有元素都在主动放慢你的节奏，让你愿意每天回来。它不是一台仪器，而是一个温柔的搭档。

色彩是情绪化的、有温度的。奶白与暖米作底，主强调色是从暖橙到粉桃的渐变，像清晨第一缕光；薄荷绿与天蓝作为营养与训练的语义色，柔和但不失辨识。渐变不是装饰，而是这套风格的语法——背景、卡片、圆环都允许色相在两个邻近色之间缓慢过渡，制造"光在流动"的感觉。每一组渐变都需被反复调和到没有生硬边界，像水彩在湿纸上自然晕开。

排版是圆润友好的。使用圆角无衬线（rounded sans），字重中等，不追求极端落差。标题温和有力，数字克制可读，标签像轻声提示。行距宽松，让文字有呼吸。没有全大写、没有拉开字距的"叫喊"——一切像朋友在耳边说话。

形状以圆为主。大圆角（20–28px）、胶囊按钮、圆环进度、圆形头像与图标。卡片之间靠柔和的间距与微妙的高度差区分，而非硬线。阴影是柔的、大的、低不透明度的，像物体浮在纸上。动效是缓的、连贯的——圆环像呼吸一样填充，数字像涨潮一样上升，没有任何"啪"的硬切。

最终成品必须看起来像一个真正关心用户心理的康养团队，花了很长时间打磨"被使用时的感受"——每一种渐变都经过情绪测试，每一个圆角都经过触感模拟，每一处留白都是为了让用户在打开 APP 的瞬间松一口气。柔和不等于廉价，相反，它需要比硬朗风格更精微的控制力。

## 排版

- 标题：圆角无衬线 semibold，28–32pt。
- 数字：圆角无衬线，中等字重，克制可读。
- 标签：圆润 regular，14pt，正常字距。
- 正文：圆润 regular，15pt，行距 1.5。

## 空间与形

- 圆角：20–28px，胶囊按钮 999px。
- 间距：以 8 为基准，区块间 20–24px。
- 阴影：大范围、低不透明度（0.06–0.1），柔浮感。
- 渐变：背景、卡片顶栏、圆环均可用 2 色柔和渐变。
- 分割：尽量不用线，靠间距与底色差。
