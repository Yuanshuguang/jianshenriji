# Editorial Minimal · 编辑级极简

> 像翻一本设计精良的健康杂志。

## 命名

**Editorial Minimal**（编辑级极简）

## 哲学

信息本身即是美。这一套语言把健身 APP 当作一本编辑严谨的健康刊物来排——每一屏都像一页杂志，有刊头、有正文、有数据图表、有页脚，层级分明，留白慷慨。它来自 Linear 的精密、Apple Health 的系统感、Cronometer 的数据诚实。它不讨好，也不冷淡，它只是"把事情讲清楚"。

色彩是极度克制的。近白底（带一丝冷灰）配墨黑文字，是这套风格的骨。强调色只有一个——靛蓝，且只用在"需要你注意"的地方：当前进度、可操作按钮、关键偏差。其余信息全部用黑、灰、浅灰三档墨色承担。色彩越少，每一个上色的元素就越有分量。这种克制需要设计者对"什么值得被看见"有极强的判断力，多上一个色，整套就垮。

排版是这套风格的灵魂。衬线字体用于标题与大数字，赋予数据一种"被认真记录"的庄重感；几何无衬线用于正文与标签，保证密度与可读。标题与正文之间有明确的字号阶梯，像杂志的 H1/H2/body。数字使用等宽变体，让一列列数据对齐成表格般的秩序。字距、行距、段距都经过编辑级的校准，没有任何"差不多就行"。

布局采用严格的编辑网格。内容靠左对齐为主，右侧留白形成"杂志页边距"。数据用极细的分割线与缩进组织成表格，而非堆叠卡片。图表是静态的、克制的——一条线、一个柱、一个点，不加装饰。所有元素在一条隐形的基线网格上对齐，这种秩序感本身就是美。

最终成品必须看起来像一位资深艺术指导亲自逐页排过——每个字距都量过，每条基线都对过，每个留白都是有意的。极简不是省事，极简是把"不必要的东西全部删掉"之后，剩下的每一个元素都精确到无法再调。它读起来安静，但每一个细节都在低声说"我很专业"。

## 色彩 Token

| Token | 值 | 用途 |
|---|---|---|
| bg | #FAFAFA | 近白冷灰底 |
| surface | #FFFFFF | 内容区 |
| line | #E4E4E7 | 极细分割线 |
| ink | #18181B | 墨黑主文字 |
| inkMute | #71717A | 辅助文字 |
| inkFaint | #A1A1AA | 次要文字 |
| accent | #4338CA | 靛蓝（唯一强调） |
| positive | #15803D | 深绿（达标） |
| negative | #B91C1C | 深红（超额） |

## 排版

- 标题：衬线 semibold，30–34pt。
- 大数字：衬线，等宽数字，36–44pt。
- 正文：几何无衬线 regular，15pt，行距 1.55。
- 标签：几何无衬线 medium，12pt，字距 +0.02em。

## 空间与形

- 圆角：8–12px，克制。
- 间距：以 4 为基准，章节间 32–40px 大留白。
- 分割：1px 极细线 #E4E4E7，靠缩进与对齐组织。
- 网格：12 列编辑网格，左侧留白边距。
- 阴影：几乎不用，靠线与底色差。
