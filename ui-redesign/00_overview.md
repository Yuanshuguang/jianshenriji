# 健身 APP 五套 UI 风格设计方案

> 本文件为总览。五套风格各自独立成文，详见同目录下的分篇。
> 每套风格均基于 2024–2025 主流移动 APP 设计趋势提炼，并针对本产品「离线优先的健身饮食动态计划助手」的核心场景（今日推荐首页：热量仪表盘 + 宏量营养 + 餐次计划 + 训练计划 + 动态调整）做了适配。

---

## 风格一　Athletic Brutalism · 竞技粗野

**一句话**：运动场记分牌，一眼读懂。

- 灵感来源：Whoop、Strava、Nike Run Club、Strong。
- 核心气质：高强度、高对比、竞技感、即时可读。
- 色彩：纯黑底 + 电光橙 / 荧光黄绿强调，留白即力量。
- 排版：超粗压缩体大数字，细小标签，落差极大。
- 适合：希望产品读起来像「专业训练设备」的用户。

详见 `01_athletic_brutalism.md`。

---

## 风格二　Soft Gradient Wellness · 柔和渐变康养

**一句话**：像晨光一样温柔地推着你走。

- 灵感来源：Apple Fitness、Calm、Headspace、MyFitnessPal 新版。
- 核心气质：柔和、亲和、个人化、可持续。
- 色彩：奶白底 + 暖橙到粉桃渐变 + 薄荷绿点缀。
- 排版：圆润无衬线，弧度友好，节奏舒缓。
- 适合：希望健身「不焦虑、可坚持」的用户。

详见 `02_soft_gradient_wellness.md`。

---

## 风格三　Editorial Minimal · 编辑级极简

**一句话**：像翻一本设计精良的健康杂志。

- 灵感来源：Linear、Apple Health、Notion、Cronometer。
- 核心气质：克制、精致、留白慷慨、层级精准。
- 色彩：近白底 + 墨黑文字 + 单一克制强调色（靛蓝）。
- 排版：衬线标题 + 几何无衬线正文，编辑级网格。
- 适合：重视信息密度与审美克制的理性用户。

详见 `03_editorial_minimal.md`。

---

## 风格四　Bento Glass · 便当玻璃

**一句话**：把今天装进一格一格会发光的便当盒。

- 灵感来源：Apple Vision Pro 玻璃质感、Bento 布局潮流、Whoop 暗色仪表盘。
- 核心气质：模块化、科技感、半透明、层次丰富。
- 色彩：深空灰底 + 毛玻璃卡片 + 青蓝/紫罗兰霓虹强调。
- 排版：几何无衬线，等宽数字，标签克制。
- 适合：喜欢「高级感 + 数据驾驶舱」的科技型用户。

详见 `04_bento_glass.md`。

---

## 风格五　Organic Earth · 有机大地

**一句话**：把健身写进自然里。

- 灵感来源：Headspace 地球色调、FitOn、Alo Moves、可持续生活方式品牌。
- 核心气质：温暖、自然、可持续、不内卷。
- 色彩：燕麦米底 + 赤陶橙 + 鼠尾草绿 + 深可可文字。
- 排版：人文衬线标题 + 温润无衬线正文，弧形分割。
- 适合：把健身视为长期生活方式、反感「卷数据」的用户。

详见 `05_organic_earth.md`。

---

## 如何挑选

| 你更在意 | 推荐风格 |
|---|---|
| 训练时一眼读懂、竞技感 | 一 · Athletic Brutalism |
| 不焦虑、可持续、亲和 | 二 · Soft Gradient Wellness |
| 信息精致、克制、专业 | 三 · Editorial Minimal |
| 科技感、数据驾驶舱 | 四 · Bento Glass |
| 自然、温暖、生活方式 | 五 · Organic Earth |

选定后，我会基于该风格产出完整的设计 Token（颜色 / 字号 / 间距 / 圆角 / 阴影）与全部页面高保真稿。
