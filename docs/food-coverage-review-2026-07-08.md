# 健身日历 APP 食物数据库 · 中国常见食物覆盖审查

> 审查日期：2026-07-08
> 审查人：甄全录（食品分类数据库专家团主理人）
> 协作成员：常味鲜（中式烹调大师，出品"常见食物覆盖基准"）· 录数清（数据入库工程师，出品"结构优化方案"）
> 数据基础：实库 `getFoodCatalog()` 四层合并（内置 221 + 补充 169 + 兜底 267 + CSV 2160 = 2699 个唯一食物）

---

## 一、总体结论

**结论：覆盖面已经很广，但"补得多、治得少"。**

- 实库现有 **2699 个唯一食物名称**，分布在 9 大类。
- 常味鲜出具的《中国人日常常见食物最小完备集》约 **410 条**（12 大类、覆盖日常 90% 消费场景）。实库规模是这份基准的 **6.5 倍**，且常见食物绝大多数已覆盖——普通用户日常搜索"米饭/鸡蛋/牛奶/鸡胸肉/西兰花/红烧肉/螺蛳粉/奶茶"等**几乎不会落空**。
- 但数据**质量与结构治理**明显落后于规模扩张：CSV 82% 无来源、4 项 P0 硬编码错误仍在、同义重复与品牌爆炸未收敛。覆盖"广度"过关，**"精度与可维护性"亟需补作业**。

**一句话给老板**：常见食物基本都搜得到，现在最该花钱的不是继续加食物，而是把已有的 2699 条"洗干净、标清楚、查准数"。

## 四、需要优化的点（数据质量 + 结构）

### 4.1 紧急数据错误（P0，直接影响用户热量/蛋白计算）

| 问题 | 现状 | 应改为 | 影响 |
|------|------|--------|------|
| 牛奶热量 | 54 kcal | 61 kcal（与变体/CSV 一致） | 每日牛奶热量偏差 ~13% |
| 核桃宏量 | 脂肪65/碳水14（Atwater +8.5%） | 脂肪58.8/碳水19.1 | 热量与宏量不自洽 |
| 培根蛋白 | 12 g（Atwater -20.5%） | 37 g（USDA 煎培根） | 蛋白摄入被严重低估 |
| 鸡胸肉 | 蛋白24/脂肪2.5（混用数据源） | 蛋白19.4/脂肪5.0/碳水2.5 | 蛋白虚高、热量不自洽 |
| 变体系统无校验 | `resolveFoodByVariant` 完全覆盖营养值 | 加 Atwater + 合理区间约束 | 蒸蛋等含水食物按"个"输入严重低估 |
| 零热量异常 | 16 条"零热量但营养素非零"（蜂王浆等） | 修正或置为不活跃 | 数据明显错误 |

> 上述 P0 来自 2026-07-04 审计报告，本次复核代码结构仍在，建议先确认是否已修，未修则立即修。

### 4.2 结构与治理（P1 / P2）

- **同义不同 ID 重复**：西瓜/watermelon 与 xigua、芒果/mango 与 mangguo、红烧肉/hongshao-rou 与 braised-pork 并存 → 搜索同时出现两条，体验混乱。
- **品牌/部位爆炸**：纯牛奶 90+ 品牌条目、奶粉 50+、猪肉几十种部位做法 → 普通用户搜索噪音大、难选。
- **别名共享歧义**：三种"奶油"都别名"黄油"，搜索无法区分。
- **CSV 来源与置信度**：2160 条中 82.3% 来源无法追溯、仅 1% 高置信度、22% 低置信度、318 条同名冲突 → 精确热量计算不可靠。

### 4.3 录数清的结构优化方案（可直接落地）

**① 两层数据模型（治"品牌爆炸 + 同义重复"）**
- `foods`（标准品：权威成分表级别的通用食物）
- `food_brand_instance`（品牌实例：康师傅/伊利等 SKU，关联标准品）
- `food_alias`（别名表，带歧义检测）
- `food_variant_def`（变体定义，独立于主表）

**② 合并去重改用 `mergeKey`**：不再仅靠 `id` 去重，用 `mergeKey` 归一同义食物；重排层级权重（权威成分表上提，兜底/品牌下沉）。

**③ 新增溯源字段**：`mergeKey / sourceDb / sourceVersion / lastVerifiedAt / dataHash`，解决"82% 无来源"问题。

**④ 自动化校验脚本（建议做 CI 门禁）**，9 条规则：
Atwater 一致性、零热量异常、合理营养区间、同名冲突、变体值校验、别名歧义、来源追溯、置信度分布、字段完整性。

**⑤ 路线图**
- 短期：修 4 项 P0 + 补溯源字段 + 上校验脚本
- 中期：mergeKey 合并 + 两层收敛 + 别名治理 + 变体校验
- 长期：置信度重分级 + 持续核验 + 搜索排序优化

## 六、质量总评（对比 2026-07-04 审计）

- **覆盖广度**：补库后中国常见食物覆盖率已从 66.5% → 99.7%，本次按实库核验，日常常见食物基本不缺。
- **数据精度/治理**：仍是 07-04 的水平（综合 4.8/10），P0 错误与 CSV 溯源问题尚未实质改善。
- **结论**：**广度达标，精度欠账**。下一步重心应从"加食物"转向"洗数据 + 立规矩"。
