# 食物数据源政策

> 最后更新：2026-07-07
> 此政策永久生效，不可被后续决策覆盖。

## 核心规则

**所有食物/营养数据源以最新《中国食物成分表》（中国营养学会 / 北京大学医学出版社）为默认权威来源。**

- 当美国 USDA 数据库与中国成分表冲突时，以中国数据为准
- 当其他非中国数据库（如 Open Food Facts、日本食品标准成分表）与中国成分表冲突时，以中国数据为准
- 仅当某种食物在中国成分表中完全不存在时，才可引用 USDA 或其他数据库，且需在 source 字段标注

## 食物数据文件职责

| 文件 | 职责 | 数据来源 |
|------|------|---------|
| shared/index.ts | 主食物目录，覆盖国人日常食材 | 中国成分表 |
| curated-foods.ts | CSV/批量导出精加工食物 | 中国成分表 + 厂商标注 |
| chinese-foods-supplement.ts | 中国特有食物补充 | 中国成分表 |
| category-fallback-foods.ts | 品类级兜底食物 | 中国成分表 |
| review-pool/pending-cn/new-foods-batch*.ts | 待审核批量导入数据 | 待确认 |
| review-pool/foreign-source-quarantine/* | Open Food Facts 等非中国来源隔离数据 | OFF |

## 校准参考

- **鸡蛋**：碳水 1.5g/100g（第 6 版，非 USDA 2.8g）
- **花生（生）**：脂肪 49.2g/100g
- **芝麻酱**：碳水 19g/100g
- **红烧肉**：蛋白 14g / 脂肪 37g / 100g（中式家常烹饪）
- **酥油茶**：碳水 ~2g / 100g（砖茶+酥油+盐）
- **蚕蛹（油炸）**：蛋白 ~22g / 100g（非干制 51g）
- **培根**：蛋白 ~20g / 100g（五花培根标准）

## 新增食物数据职责

1. 首要查证《中国食物成分表》最新版
2. 如采用 USDA 数据，需在 source 字段标注 "usda"
3. 中式烹饪菜品需按中式标准估算，不可照搬 USDA
